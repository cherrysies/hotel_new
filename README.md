# Система управления гостиницей
## Функциональность
* Авторизация пользователей с тремя ролями: Администратор, Менеджер, Клиент
* Каталог номеров с поиском, фильтрацией и сортировкой
* Управление номерами (добавление, редактирование, удаление) — только для администратора
* Создание и управление бронированиями
* Разграничение прав доступа в зависимости от роли пользователя
## Запуск проекта
```
git clone git@github.com:cherrysies/hotel_new.git
docker-compose up -d
cd HotelApp
dotnet run
```
